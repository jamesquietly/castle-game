This is a Castle card game built with Next.js and PeerJS

## How to start a game
### Hosting a game
 - Enter player name
 - Click Host Game to create a game
 - Copy invite link and send to friends
 - Wait for all players to join
 - Click Start Game to begin

### Joining a game
 - Join the game using the invite link
 - Enter your player name

## Game Flow / Rules
 - Each player starts with 3 cards in their hand, three cards face up, and three cards face down
 - In the dealing phase, you can swap out cards in your hand with cards that are face up
 - During play, each player takes turns playing cards
 - The card played must be higher or equal to the previous card. Suit does not matter.
 - First player to play all their cards wins.
 - There are special cards that can be played at any time
   - 10 gets rid of the current pile
   - 7 next player need to plays a card lower than 7
   - 2 the current player resets the pile and can play any card



## Getting Started

To run the development server:

```bash
pnpm install
pnpm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
